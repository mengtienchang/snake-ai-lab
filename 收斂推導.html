臨界局數 k 的完整推導：從「誤差」出發

接續你的出發點——假設存在臨界值 k，使累積平均達到理想值 m——把卡住的地方修好，一路推到能帶入實驗數據的公式。

0你卡住的地方，以及為什麼會卡

你的出發點是：存在臨界值 k，第 k 局時累積平均恰好等於理想值 m。移項得：

k·m = n1 + n2 + … + nk

接著做誤差思考是對的方向：把每局分數拆成「真實實力＋當局運氣」：

ni = m + εi εi：第 i 局的隨機偏差。好地圖為正、壞地圖為負；平均是 0，變異數是 σ²（σ ＝ 單局分數的標準差）

代回去展開：

k·m = (m+ε1) + … + (m+εk) = k·m + Σεi
死胡同出現了：兩邊的 k·m 互相消掉，剩下 Σεi = 0——「前 k 局的運氣恰好完全抵消」。這是機率為零的巧合；而且就算某局真的路過 m，下一局又會被帶走。累積平均會無限次穿越 m，卻永遠不會「到達之後停住」。推不動不是你的代數錯了，是「精確等於」這個目標本身太強，任何人從這裡都推不下去。

1修改目標：把「等於」放寬成「管子」

我們真正在乎的不是曲線碰到 m，而是它被困在 m 附近。所以自己選一個容忍度 ε（例如「差 35 分以內就算到位」），把目標改成：

| ek | ≤ ε，　其中　ek := n1+…+nkk − m ek：跑到第 k 局時，累積平均離真實值還差多少

2誤差的結構：平均是零，關鍵在晃多大

用 ni = m + εi 改寫誤差：

ek = (m+ε1)+…+(m+εk)k − m ＝ ε1+…+εkk

訊號 m 完全消掉了——誤差就是 k 局運氣的平均。它的期望值是 0（運氣不偏袒任何方向），所以問題只剩一個：它典型會晃多大？這由變異數回答。

3晃動要怎麼量？——為什麼偏偏是「平方的平均」

ek 的平均是 0，但「平均為零」不等於「很小」——它可能在 +200 和 −200 之間狂甩，平均照樣是零。所以我們要量的是典型偏離多遠，方向不重要。

最直覺的做法是取絕對值的平均 E[|ek|]。這個定義沒有錯，但它在代數上是死路：|ε1+…+εk| 沒有任何展開法，推導到這裡就會停住。

所以改用平方來消掉方向：定義晃動的度量為「偏差平方的平均」E[ek²]，用完再開根號回到原尺度。選平方不是天上掉下來的規定，而是一個務實的取捨：「和的平方」是唯一能完全乘開的東西——(a+b)² = a²+2ab 這種國中代數，就是下一節整個推導的全部工具。這個「平方的平均」就是變異數（Var）的定義，開根號後叫標準差；也就是說，你看過的那些 Var 公式不是公理，只是這個定義乘開括號後的結果——下一節我們不套任何公式，直接算給你看。

4不套公式，從定義硬算（整個推導的心臟）

目標：算 E[ek²]。第一步只是把 1/k 提出平方外（平方裡的常數提出來要平方，(x/k)² = x²/k²，國中代數）：

ek² = (ε1+…+εk)²k²

第二步，乘開分子那個平方。(a+b)² = a² + b² + 2ab；k 項的版本一模一樣——每一項自己平方，加上所有兩兩相乘的交叉項：

(ε1+…+εk)² = Σi εi² ＋ Σi≠j εiεj 左邊那堆：k 個「自己乘自己」。右邊那堆：k(k−1) 個「第 i 局乘第 j 局」。到此為止純代數，一點機率都沒用到。

第三步，兩邊取平均（期望值）。平均可以逐項做，所以只要分別搞定兩種項：

「自己乘自己」的項：E[εi²] 是「單局偏差平方的平均」——這不是未知數，它就是我們從 100 局數據裡實際量出來的那個 σ²（sd 的平方）。k 項共貢獻 k·σ²。

「兩局互乘」的交叉項：E[εiεj] 是什麼？想像把第 i 局和第 j 局的運氣配成一對：兩局同號（都好或都壞）時乘積為正，異號時乘積為負。因為兩局用獨立種子、互不知道對方，「同號」和「異號」的出現既不偏多也不偏少，正負貢獻恰好打平——平均是 0。代數上這件事寫成：獨立 ⟹ E[εiεj] = E[εi]·E[εj] = 0×0 = 0。k(k−1) 個交叉項全數陣亡。

E[(ε1+…+εk)²] = k·σ² ＋ 0 　⟹　E[ek²] = k·σ²k² = σ²k 　⟹　典型晃動 SE(k) = σ√k
回頭看就懂 √k 的出身了：分子乘開後本來有 k² 個項，交叉項全滅、只活下 k 個，所以分子只長 k 倍（開根號後 √k 倍）而不是 k² 倍——「運氣互相抵消」這句直覺話，代數上就是交叉項歸零。這也是獨立性唯一的出場：如果局與局相關（共用亂數流、狀態延續），交叉項不為零，那 k(k−1) 個殭屍會讓誤差縮得遠比 σ/√k 慢。而教科書那兩條「性質」——Var(aX)=a²Var(X)、獨立和的 Var 相加——不過是這次乘開括號的第一步和第三步各自的名字。

5解出臨界值 k*

要求晃動不超過容忍度：SE(k) ≤ ε，移項：

σ√k ≤ ε 　⟹　 k* = σ²ε² = (σ／ε)²

這就是你在找的臨界值。注意它的兩個性格：對 σ 平方敏感（單局越亂，代價平方成長）、對 ε 平方敏感（精度要求加倍，局數要翻四倍——報酬遞減的根源）。

要說得更嚴格，把「典型晃動」升級成機率保證：切比雪夫不等式給保守版 k ≥ σ²/(ε²δ)（失敗機率 ≤ δ）；中央極限定理給實用版：

k* = (1.96·σ／ε)² 95% 信心水準。1.96 換 2.58 就是 99%。這條就是統計學教科書裡「樣本數規劃」（sample size determination）的標準公式——你的推導路線正是它的骨架。

7整條推理鏈的全景

① 精確等式推不動（Σε = 0 是巧合事件）→ ② 換成容忍帶 |ek| ≤ ε → ③ 拆解 ni = m + εi，誤差＝運氣的平均 → ④ 晃動用「平方的平均」來量——因為絕對值拆不開、平方乘得開 → ⑤ 乘開括號：k 個平方項留下 kσ²，k(k−1) 個交叉項因獨立而歸零，得 SE = σ/√k → ⑥ 移項解出 k* = (σ/ε)²，再用 CLT 加上信心水準。你原本卡的關卡有兩個：②（把等式換成管子）和④⑤（為什麼用變異數、公式從哪來——答案是：那不是公式，是一次乘開括號）。獨立種子的實驗設計，保的正是⑤裡交叉項歸零那一步。
