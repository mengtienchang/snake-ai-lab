# Snake AI Lab 🐍

一個用來**觀察演算法行為**的貪吃蛇實驗場（pygame）。

不只是遊戲 —— 內建三種自動模式演算法可即時切換對照，配上體力（飢餓）、
地形代價、限時道具等環境機制，用來研究一個問題：

> **環境規則改變時，哪一種演算法的數學保證還成立？**

例如：古典貪吃蛇的必勝解法（漢米爾頓迴路）在加入「體力」機制後會餓死 ——
因為它的安全保證建立在「等待免費」的世界裡，而體力機制本質上是一條
「平均 N 步內必須進食」的配速線。

## 執行

```bash
python3 -m venv .venv
.venv/bin/pip install pygame-ce
.venv/bin/python snake_game.py
```

macOS 也可以直接雙擊 `啟動貪吃蛇.command`（會自動建環境）。

## 操作

| 按鍵 | 功能 |
|---|---|
| 方向鍵 / WASD | 轉向 |
| 空白鍵 / P | 暫停 |
| R / Enter | 重新開始 |
| **T** | 自動模式 開／關 |
| **G** | 切換演算法：BFS → DIJ → HAM |
| ESC | 離開 |

按鍵用實體位置（scancode）判斷，中文輸入法開著也有效。

## 三種演算法

| | 策略 | 特性 |
|---|---|---|
| **BFS** | 最短路＋吃完追得到尾巴才走＋跟尾巴等機會 | 貪婪流對照組，進食效率最高 |
| **DIJ** | 按體力代價找最省的路＋恐慌賭路＋藍蘋果減重 | 規則更多，不一定更強 —— 手寫規則的天花板展示 |
| **HAM** | 漢米爾頓迴路＋編號捷徑（perturbed Hamiltonian） | 數學上不可能撞到自己；但在體力機制下會餓死 |

畫面上會即時顯示 AI 當下的決策模式（追紅蘋果／跟尾巴等機會／純循環…），
所有行為同步寫入 `行為記錄.txt`（人讀）與 `行為記錄.jsonl`（程式分析）。

## 環境機制（都在 `environment/config.py` 可調）

- **體力**：每步 -1，歸零餓死；吃蘋果回補。`ENERGY_RED` 就是配速線 ——
  調高它，古典流派就能活；調低它，連貪婪流都窒息
- **紅蘋果** +10分/長1節/體力+30、**金蘋果** +50分/長3節（限時）、
  **藍蘋果** -20分/減3節（減重與分數的權衡，限時）
- **碎石地**（體力消耗×3）、**石頭**（撞死）、**傳送門** —— 各有開關，
  預設全關（乾淨棋盤觀察演算法本體）

## 專案結構

```
snake_game.py     入口＋介面層（畫面、音效、輸入、行為記錄）
environment/      環境機制
  config.py       所有參數與開關
  game.py         規則本體（無視窗可跑，可接批量模擬／RL）
algorithms/       演算法（介面統一：fn(game) -> (方向, 模式標籤)）
  pathfind.py     BFS / Dijkstra / 前向模擬
  greedy_bfs.py   greedy_dij.py   hamilton.py
```

新演算法照統一介面寫好、加進 `algorithms/__init__.py` 的 `AUTO_ALGOS`，
就會自動出現在遊戲的 G 鍵輪換裡。

## 目前的實驗結論（乾淨棋盤 + 體力可累積）

| 流派 | 典型結局 |
|---|---|
| 貪婪流（BFS/DIJ） | 長度 ~120-180（20-29% 地圖），死於幾何（自己困死）或晚期餓死 |
| 古典流（HAM 各變體） | 安全但餓死於 ~30+ 步/顆的前跳約束幾何下界 |

環境的體力參數決定了哪個流派勝出 —— 這正是這個實驗場想展示的事。
